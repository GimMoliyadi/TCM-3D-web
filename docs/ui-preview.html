中医穴位图谱 · UI 升级静态预览

本页用真实的样式表（source/styles/*.css 与 dietary.css）加静态 DOM 复现应用外壳，用于在没有工具链的环境下目视核对 设计语言、信息层级与三端布局。响应式断点已改写为 @container， 因此可以在同一页面并列展示桌面 1280 / 手机 390 两种结果。

⚠️ 这不是运行时截图。3D 人体模型与 290 个穴位标记是 WebGL 渲染，需要执行 npm run dev 或 npm run build 后由 Playwright 抓取。 本机 WorkBuddy 的命令执行运行时（cli/dist）缺失，本轮无法执行构建与截图。

一、设计 token：米白 · 竹青 · 淡墨

页面底用米白与宣纸，主强调用竹青，正文用淡墨，穴位标记与禁忌用朱砂，功效提示用赭石。 3D 舞台单独使用中性深灰，让模型与红色标记获得最高对比度。

使用说明

穴位分类

  • 点击页头「穴位分类」打开分类面板
  • 可切换「按部位」或「按症状」两种查找方式
  • 展开分类后点击穴位名称，自动定位并显示详情

搜索

  • 用 ↑ ↓ 在结果间移动，回车定位，Esc 清空

鼠标操作

  • 左键拖动：旋转视角
  • 右键拖动：平移画面
  • 滚轮：缩放

键盘

  • Esc 关闭面板并重置视角；Tab / Enter / Space 在控件间移动与激活

使用说明：右下角浮层，可 Esc / 右上角关闭。
