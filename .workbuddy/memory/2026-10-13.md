## TCM-3D-web 前端 UI/UX 与工程结构升级（分支 feature/ui-ux-upgrade）

**目标**：把 643 行 `App.js` 巨石 + Tailwind 工具类 + 深蓝青霓虹配色的 3D 演示页，
升级为「token 化样式 + 组件化 + 数据访问层解耦」的中医知识可视化应用骨骼。

**已完成**
- 样式分层：`source/styles/{tokens,base,layout,components,panels}.css`，index.css 按层聚合。
  设计语言：米白/竹青/淡墨/朱砂/赭石 + 3D 舞台中性深灰；全部 token 化，支持 reduced-motion。
- 组件拆分（`source/components/`）：
  - `ui/index.jsx`（Button/IconButton/Badge/SegmentedControl/Spinner/StateBlock/Loading/Empty/Error/SectionCard/DetailCard）
  - `layout/`（AppHeader、StageToolbar、UsageGuide）
  - `acupoints/`（SearchPanel、CategoryPanel、AcupointDetail）
  - `three/`（Viewer、ModelScene、CameraController、AcupointNode）
  - `dietary/` 既有 5 组件保留业务逻辑，仅重制 dietary.css 与排版
- 数据层：`source/data/repository.js`（fetchAcupoints 可替换为 FastAPI）+ `hooks/useAcupoints`（loading/ready/error/reload）
  + `hooks/useMediaQuery`。组件不再直接 import JSON。
- 布局：三区栅格（左 320 可收起 / 舞台自适应 / 右 400）；≤1180 左栏变抽屉；≤860 面板变底部 sheet（46dvh）；
  ≤640 页头折两行。面板不覆盖模型。
- 无障碍：Esc 分层关闭、搜索 ↑↓/Enter/Esc、:focus-visible 焦点环、skip-link、44px 触控热区。
- 测试：新增 `tests/ui-behavior.test.cjs`，守护相机/模型公式、搜索谓词、无障碍名称、设计 token、模块边界。
- 文档：`docs/ui-redesign.md`（方案）、`docs/ui-upgrade-summary.md`（改造总结）、`docs/ui-preview.html`（静态设计预览）。
